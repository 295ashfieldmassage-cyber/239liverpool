# 239 Liverpool website

## Update the weekly roster

Open `roster-config.js`. Update `dateRange`, then edit the people listed under Monday through Sunday. Each person has a name, short description and image path. No HTML editing is required.

## Languages

The website supports English, Chinese, Vietnamese, Arabic, Japanese and Korean.

## Photo hover

The normal portrait is the A image. Optional alternate images are configured in `hoverPhotoData` at the top of `script.js` and rotate every 30 seconds while hovered.

Only publish profile photographs with permission.
